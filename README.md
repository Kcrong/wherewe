# Wherewe

Wherewe helps you record meetings, follow conversations with transcription and
translation, and keep meeting material organized on your Mac.

## Features

- Record microphone and optional system audio.
- Read transcripts and translations during and after meetings.
- Translate between English, Korean, Japanese, and Chinese.
- Search and edit transcripts.
- Attach documents, manage glossary terms, and export meeting records.

## Requirements

- Apple Silicon Mac.
- macOS 26 or later.
- Required Speech and Translation language packs installed in macOS.
- A configured audio input route when recording system audio.

## Install

Wherewe is not currently distributed as a downloadable app. Installation
instructions will be added with the first verified macOS package.

## Privacy

Meeting content stays on your Mac. Wherewe uses macOS system language
capabilities and does not require an external AI service or model runtime.
